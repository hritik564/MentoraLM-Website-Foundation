MENTORALM MAIN WEBSITE — PHASE 0
FOUNDATION + ARCHITECTURE ONLY

We are building a completely new production marketing website for MentoraLM.

This is a NEW project.

IMPORTANT:
This is Phase 0 only.

DO NOT build the homepage sections yet.
DO NOT build the Hero yet.
DO NOT build module cards yet.
DO NOT build animations yet.
DO NOT create placeholder marketing sections.

- Vite

- database
- authentication
- API integrations
- CMS
- analytics

- 3D engines
