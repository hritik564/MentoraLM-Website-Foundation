==================================================

MentoraLM is an education + career ecosystem powered by intelligent technology and human expertise.

The website should eventually feel like:

- a serious technology company
- a premium education platform
- a career ecosystem
- intelligent
- trustworthy
- modern
- ambitious
- human
- youthful without being childish

Avoid the visual language of:

- generic AI startups
- cryptocurrency websites
- SaaS templates
- generic coaching websites
- university websites
- excessive glassmorphism
- excessive neon
- generic "AI robot" imagery

The design should communicate:

CLARITY
INTELLIGENCE
GROWTH
OPPORTUNITY

==================================================

The old MentoraLM website experiment was too minimalist and too focused on demonstrating a design system.

Do NOT repeat that mistake.

The new system must support a website with meaningful visual density.

The final website should be capable of using:

- editorial sections
- product interfaces
- interactive visualisations
- diagrams
- cards
- timelines
- progress systems
- dashboards
- data-like UI
- product previews
- storytelling sections

The design system must therefore support both:

EDITORIAL MOMENTS

and

PRODUCT MOMENTS.

==================================================
5. TYPOGRAPHY
==================================================

Create a reusable typography system.

PRIMARY UI/BODY FONT:

Use a modern, highly readable sans-serif.

The font should work well for:

- navigation
- body copy
- labels
- buttons
- metadata
- product interfaces

DISPLAY FONT:

Use a sophisticated serif/editorial font for major brand statements and selected large headlines.

The existing MentoraLM direction has already established this serif/sans combination.

Preserve that conceptual direction.

Do NOT turn every heading into serif.

--------------------------------------------------
TYPOGRAPHY HIERARCHY
--------------------------------------------------

Create reusable styles/tokens for:

Display XL
Display L
Display M

Heading XL
Heading L
Heading M
Heading S

Body L
Body M
Body S

Label
Eyebrow
Metadata

Button

The system must be responsive.

Large desktop typography should scale down intelligently on tablet/mobile.

Do not simply use enormous text everywhere.

==================================================
6. LAYOUT SYSTEM
==================================================

Create a consistent container/grid system.

The website should support:

- full-width sections
- constrained content sections
- split layouts
- asymmetric layouts
- product visualisations
- editorial layouts
- card grids
- full-screen interactive scenes

Desktop content should have generous but controlled horizontal margins.

Avoid excessively narrow content.

Avoid excessive empty space.

The system should allow a section to feel visually rich without becoming cluttered.

==================================================
7. SPACING SYSTEM
==================================================

Create centralized spacing tokens.

Use a consistent rhythm.

Avoid arbitrary values scattered throughout CSS.

The system must support:

- compact UI spacing
- card spacing
- section spacing
- large editorial spacing
- mobile spacing

IMPORTANT:

Large sections should have breathing room.

But do NOT default every section to huge vertical padding.

Spacing should depend on content density.

==================================================
8. BUTTON SYSTEM
==================================================

Create reusable button components/styles.

PRIMARY:

MentoraLM dark/navy button.

SECONDARY:

Light/outlined button.

ACCENT:

Controlled gradient/accent button where appropriate.

Buttons should support:

- default
- hover
- active
- focus
- disabled

Buttons should feel premium and substantial.

Avoid oversized pill-shaped buttons everywhere.

Use rounded corners that feel modern but not cartoonish.

Arrow indicators such as:

→

or

↗

may be used selectively.

==================================================
9. CARD SYSTEM
==================================================

Create a reusable card foundation.

Cards must support:

- standard cards
- product cards
- feature cards
- dark cards
- accent cards
- interactive cards
- upcoming/disabled-looking cards

Default card characteristics:

- clean surface
- subtle border
- restrained shadow
- moderate radius
- generous but not excessive padding

Avoid making every component a floating rounded rectangle.

The card system should also support cards that visually integrate into larger layouts.

==================================================
10. BORDERS
==================================================

Use subtle borders.

Prefer low-contrast borders over heavy outlines.

Borders can become slightly stronger during:

- hover
- focus
- selected state

Do not use thick borders everywhere.

==================================================
11. SHADOW SYSTEM
==================================================

Create a restrained shadow hierarchy:

- none
- subtle
- elevated
- modal

Avoid large blurred shadows that make the site look like a generic SaaS template.
